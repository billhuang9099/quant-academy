# 量化学堂 · 实践版 v4

面向 Python 零基础学习者的股票与 ETF 量化研究课程。纯静态应用，无外部运行时依赖，可运行于 GitHub Pages。仓库附带浏览器脚本包，避免直接打开本地 HTML 时的 ES Module 跨源限制。

## 学习路径

10 个模块、30 节课：Python 入门 → 市场机制 → 收益与风险 → 数据质量 → 研究方法 → 策略逻辑 → 回测验证 → 组合管理 → 模拟执行 → 策略项目。

每课有五个固定步骤：

1. **概念**：分段解释、类比、公式及变量、官方参考资料；
2. **推导**：逐步手算、结论与易错点；
3. **实验**：改参数、观察结果、保存自己的解释；
4. **检验**：两道理解检查、即时反馈、错题与间隔复习；
5. **应用**：下载 Python 起始代码，在自己的电脑运行，提交结果说明与自评。

学习空间固定显示步骤和前后导航，仅阅读区滚动。支持课程搜索、每课笔记、断点续学、手机目录，以及 Alt + 左右方向键切换步骤。浏览页面不会自动获得“掌握”标记。

## 交互与实践

- 七个实验：复利/回撤、风险仓位、成本、未来数据泄漏、均线回测、组合相关性、模拟订单；
- 浏览器回测：前一日收盘生成信号、下一日开盘执行，现金与持仓逐期核算，计入费用与滑点；
- 默认仅展示训练区间；主动查看样本外区间后，该数据集标记为“已查看”，不能再当作全新验证；
- 可导入 `date,open,close,volume` CSV，并检查日期、排序、价格和成交量；
- 配套 `practice/research.py` 使用 Python 标准库，输出指标、逐日权益与交易记录；
- 策略项目：研究计划、代码运行记录、手工核对、前向模拟日志、异常演练及 Markdown 导出。

演示行情为固定种子生成的合成数据，排除周末但不模拟交易所节假日。浏览器与 Python 回测仅是教学模型：允许小数股，不包含真实券商、复权/退市处理、所有市场交易限制和账户税费。它不连接券商，不会下真实订单。

## 成果边界

目标是让学习者能够独立研究并复核一个低频策略，不承诺收益或实盘资格。“记录完整”只表示客观题、实验解释和作业留档达到课程要求，不能证明文字正确或交易能力。前向模拟日志的日期与完整性检查也不是外部审计。20 个真实交易日仅是教学最低观察长度，不能据此判断策略长期有效。

## 保存与云同步

学习记录默认保存在当前浏览器。顶部“云同步”使用 GitHub Secret Gist；第一台设备首次同步可自动创建，其他设备填写相同 Gist ID。

- classic Personal Access Token 仅需 `gist` 权限；默认只在本次浏览器会话保存；
- Token 不进入进度数据、备份或日志，只发给 GitHub 官方 API；
- **Secret 不等于加密**：知道 Gist 链接的人可能读取内容，不要保存账户凭证或敏感财务资料；
- 每台设备写独立数据文件，拉取时合并各设备记录，避免同时同步覆盖整份进度；
- 同一字段按记录时间与写入者 ID 决胜；同一段文字不提供字符级协同编辑，重要内容另行备份；
- 支持 JSON 导出与合并导入；损坏或超出容量的数据会明确报错；
- 兼容旧版数据与已有 Gist ID，旧进度保留，但不直接抵扣新版测验与作业；所有设备应刷新为 v4。

浏览器本地文件地址、localhost 和 GitHub Pages 属于不同存储来源；换入口时请先从原入口同步或导出备份，再在新入口导入/拉取。应用更新不会自动搬移不同来源的存储。

## 本地运行与验证

```bash
python3 -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765

npm run check
npm test
npm run test:python
# 修改源码后生成浏览器脚本包
npm ci
npm run build
```

Python 项目运行说明见 [practice/README.md](practice/README.md)。使用标准库的示例不需要安装依赖；pandas 入门课按课内步骤单独安装 pandas。

源码入口为 `src/academy/app.js`，发布入口为 `index.html` → `academy.bundle.js`。构建工具 esbuild 固定版本并提交锁文件。历史 `src/learning` 与 `src/immersive` 保留兼容测试，但不再挂载界面。数据模型为 schema v3。部署 GitHub Pages 时保留整个仓库目录结构。
