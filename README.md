# 量化学堂

从基础认知到 Python 实战的系统化量化学习课程。

## 学习系统 v2

- **第 0 周 Python 预备营**：环境、pandas、rolling/shift、首个可审计回测；
- **掌握度地图**：按每个模块四道客观题的最近结果计算，单独展示知识覆盖置信度；
- **自动错题本**：模块测验答错后自动记录薄弱知识点；
- **间隔复习**：按 1/3/7/21/45 天逐步延长复习间隔；
- **云端合并**：作答事件、预备营状态和复习计划与原课程进度一起进入私有 Gist；
- **兼容旧数据**：原有本地学习进度与云同步 schema v1 会自动升级，不清空已完成课节。

## 云同步

学习进度默认保存在浏览器本地。点击顶部“连接 Gist 云同步”，可以使用自己的私有 GitHub Gist 在电脑和手机之间同步：

- 推送前先拉取，按完成状态、答案、验证状态和学习位置分别合并；
- 同一字段采用时间戳与设备 ID 稳定决胜，取消完成状态也能正确同步；
- GitHub Token 只发往 `api.github.com`，绝不会写入 Gist 进度内容；
- 默认仅在当前浏览器会话保存 Token，并支持一键清除；
- 支持 JSON 导入/导出，导入时合并而非清空现有学习记录；
- 首次同步自动创建私有 Gist，其他设备填写同一 Token 与 Gist ID 即可接续。

申请 GitHub classic PAT 时只需勾选 `gist` 权限。
